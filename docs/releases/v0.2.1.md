# Den Duty v0.2.1

Bug fixes for v0.2.0, mostly around approvals and photo proof.

## Install

- **Docker / Unraid:** `ghcr.io/spacegoose02/den-duty:0.2.1` (or `:latest`). The Unraid template is in `unraid/den-duty.xml`.
- **Windows:** the `.exe` below (a desktop shell for your Den Duty server).
- **Android:** the `.apk` below (sideload; a wrapper for your Den Duty server).
- Or open `/download` on your server: it offers the right app for each device.

## Fixes

**Approvals**
- Chores worth 0 points can be approved.
- **Approve all** keeps going past a chore it can't approve, and says how many didn't go through.
- Kids now see the "approved!" confetti and the parent's cheer for chores they marked done in the same sign-in.
- Undoing an approval stops at zero when the kid has already spent the points (unless the home allows negative balances), and tells the parent.

**Photo proof**
- "Not yet" on a photo chore clears the photo so the kid takes a new one, and an old cached picture is no longer shown.
- Picking a photo works on more phones and tablets. Files that can't be read (such as HEIC) show a message instead of doing nothing.
- Parents ticking off a photo chore themselves aren't sent to the camera.
