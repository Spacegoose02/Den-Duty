# Den Duty v0.8.0

Read-aloud can use your own Kokoro voices, and Helpdesk "Buy something" asks now go to Nighttime Ninja.

## Install

- **Docker / Unraid:** `ghcr.io/spacegoose02/den-duty:0.8.0` (or `:latest`). The Unraid template is in `unraid/den-duty.xml`.
- **Windows:** the `.exe` below (a desktop shell for your Den Duty server).
- **Android:** the `.apk` below (sideload; a wrapper for your Den Duty server).
- Or open `/download` on your server: it offers the right app for each device.

## What's new

**Kokoro voices for read-aloud**
- Settings → **Read-aloud voice** points Den Duty at your own Kokoro speech server (such as Kokoro-FastAPI). Pick a voice and try it.
- Every 🔊 button and the routine player then read with that voice. Kids set to Spanish or French get a Kokoro voice in their language.
- Den Duty's server fetches and caches the audio, so tablets never need to reach Kokoro. If Kokoro is off, down, slow or has no voice for the language, the device's own voice reads as before.

**Helpdesk "Buy something" goes to Nighttime Ninja**
- With Nighttime Ninja linked, a kid's "Buy something" ask also shows up in Nighttime Ninja's Requests tab.
- A yes there shows the kid "Yes! It's on the shopping list" with the list's name; a no shows "Not this time".
- Answering, closing or taking the ask back in Den Duty withdraws it from Nighttime Ninja. Asks already waiting go over when you link Nighttime Ninja, or on upgrade if it's already linked.
