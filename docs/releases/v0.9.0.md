# Den Duty v0.9.0

Den Duty now links to BookBandit: reading kids do there counts toward their Reading practice, and finishing a book can pay a bonus.

## Install

- **Docker / Unraid:** `ghcr.io/spacegoose02/den-duty:0.9.0` (or `:latest`). The Unraid template is in `unraid/den-duty.xml`.
- **Windows:** the `.exe` below (a desktop shell for your Den Duty server).
- **Android:** the `.apk` below (sideload; a wrapper for your Den Duty server).
- Or open `/download` on your server: it offers the right app for each device.

## What's new

**BookBandit reading counts toward practice**
- Make a **control** token named BookBandit (Settings → Home Assistant and API tokens), paste it into BookBandit with Den Duty's address and your home id, then pick each kid's Reading practice there.
- Every few minutes BookBandit sends each kid's reading minutes for the day. They count like a kid's own "I did it!": trusted practices count straight away, others wait for a grown-up's OK, and the practice's points pay once a day.
- Repeated reports only add the difference, and the kid's own taps still count on top. BookBandit can catch up on the last 7 days for books read offline.

**"Finished a book" bonus**
- Settings → **BookBandit** sets a bonus for finishing a book (0 = off), paid once per book.
- Optionally a grown-up checks finished books first: they wait on the parent home's **Practice to check** card, and the ledger row names the book.

See [docs/bookbandit.md](../bookbandit.md) for setup and the API.
